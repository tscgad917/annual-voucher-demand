# 年度大量傳票需求管理系統

本專案為獨立的年度大量傳票需求管理系統，與既有「大量印刷品統計／紙張需求」系統分開維護。

## GitHub Pages

- 填報頁：`https://tscgad917.github.io/annual-voucher-demand/`
- 管理頁：`https://tscgad917.github.io/annual-voucher-demand/admin.html`
- 管理入口：由「總務課統一管理中心」SYSTEM 05 進入。

## 使用的後端

- 沿用既有 Supabase 專案及管理員登入授權。
- 本系統使用獨立的 `general_survey_*` 資料表與 `general-survey-images` 圖片桶。
- 不修改庫存、紙張需求、活動報名等既有系統資料表。

## 初次啟用前注意

1. 先檢視 `schema.sql`，確認資料表、RLS、RPC、Storage policy 與既有 Supabase 結構相容。
2. **目前尚未執行 schema.sql，也尚未建立資料表或圖片桶。**
3. GitHub Pages 尚須確認已設定為從 `main` 分支的根目錄發布。
4. 完成部署後，先測試管理中心登入、SYSTEM 05 入口、管理後台授權及公開填報頁，再建立正式年度問卷。
5. 請勿將社員印鑑卡、身分證件或其他敏感個資上傳至公開圖片桶。

## 第一版功能規劃

- 建立年度問卷及設定開放、截止時間。
- 指定填報單位及管理題目、選項、圖片。
- 複製既有年度問卷。
- 同一單位於開放期間可重複提交，以最後一次提交內容為準。
- 查看填報進度及匯出 CSV。

## 重要限制

第一版填報端不要求登入，填報者選擇單位並自行輸入姓名；這不是強身分驗證。填報網址應僅提供指定單位。正式啟用前，應確認年度題目、品項名稱、選項及數量單位均正確。
